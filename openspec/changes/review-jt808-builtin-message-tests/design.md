# Design

## Context

全包包含 116 个顶层生产类型；request、response 以及 jt1078 消息已有对应测试，但部分支持类只有间接覆盖。文件数据上传使用独立消息体格式；位置扩展通过共享 Map 编解码器嵌入 0200；8105 命令由偏移量及分号分隔的数据组成。动机见 `proposal.md`。

## Goals / Non-Goals

以可复现的固定报文和边界断言补足全包实际遗漏，不按文件数量机械生成 getter/setter 测试，不扩展协议类型。

## Decisions

- 有独立格式的消息使用原始消息体测试；嵌套位置项通过生产编解码器验证类型和值，覆盖 0x66 的空列表及多事件分支。
- 检查 CustomParameterListFieldCodec 的未知参数回退、类型标记与错误编码，以及位置附加项各类型及相邻记录边界。
- 8105 直接测试不同 readerIndex 下的空字段、偏移排序与重复偏移；重复偏移使用最大容量受限的输出缓冲区，避免旧实现无限写入。
- mixed 示例按字段独立计算固定字节并断言，所有自行持有的缓冲区用 finally 释放。
- 0608 补充矩形、多边形、路线的相邻记录分派、空集合与不支持类型；复查所有可识别固定报文的校验和。

## Risks / Trade-offs

- 原始数据与 JT808 帧格式混淆 → 文件上传仅测其消息体，其他消息使用真实消息 ID 和协议头。
- 新断言揭示既有缺陷 → 先保留失败证据，再对相关注解或编解码逻辑做最小修复。
- 部分支持类型为接口、抽象基类或空标记 → 通过实际消息路径验证，不以独立测试类数量宣称分支覆盖率。
