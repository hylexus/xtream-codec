# Proposal

## Why

前两轮补齐了 request 和 response 的消息测试，但整个 builtin.messages 还包含苏标附件及位置扩展、共享编解码器、8105 子包和 mixed 示例。整体复查发现未覆盖的消息、仅打印或仅检查引用计数的测试，以及自定义编解码器边界分支遗漏。

## What Changes

- 补充文件数据上传、苏标位置扩展和位标志转换的有效固定报文测试。
- 补充共享编解码器的类型分派、未知参数、条件字段和 8105 命令偏移边界测试，最小修复复现的问题。
- 将 mixed 中无报文断言的测试改为固定输出验证，补充 0608 嵌套消息分派及扩展字段遗漏断言。
- 核对全包覆盖映射和已知报文校验和，运行 JT808 完整测试及相关检查。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

无。本次为已有行为补充回归测试及相关实现修复，设置 `skip_specs: true`。

## Impact

涉及 JT808 内置消息测试、必要的消息注解及自定义编解码器修复，不增加依赖或公共 API。保留前两轮修改和无关工作区文件。
