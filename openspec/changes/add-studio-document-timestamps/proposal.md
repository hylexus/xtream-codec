# Proposal

## Why

共享报文工作区需要提供基本的时间信息，便于判断报文何时建立及最近是否修改。现有服务器只记录 `updatedAt`，界面未提供完整时间查看入口；本次只补齐时间信息。

## What Changes

- 服务器创建报文及目录时记录创建时间和最后更新时间，后续成功保存、重命名或移动只更新最后更新时间。
- 在目录提示和当前报文的信息入口显示两种时间，未保存报文显示尚未保存。
- 兼容旧文件、SQLite 和备份数据：缺失的创建时间保留为未知，界面显示“未记录”；导入产生的新条目记录新的创建时间。
- 保持共享工作区，不引入用户、密码、报文归属或权限。

## Capabilities

### New Capabilities

- `studio-entry-timestamps`：服务器条目的创建及更新时间、持久化兼容与界面展示。

### Modified Capabilities

无。现有 Studio 工作区规格位于尚未归档的 `upgrade-codec-studio-workspace`，本次通过新增规格补充时间能力。

## Impact

涉及 Studio 后端条目合同、创建/更新/导入和目录响应，前端元数据及信息展示，后端文件与 SQLite 合同测试、UI 浏览器验证及说明文档。不新增依赖或数据库表。
