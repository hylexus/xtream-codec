# Proposal

## Why

JT/T 808 内置响应包的 50 个消息类中有 5 个缺少独立测试，已有测试还存在解码报文使用错误消息 ID、参数示例仅测试编码和字段断言遗漏，需要补齐有效的编解码回归验证。

## What Changes

- 为四个 2019 版区域/路线消息及平台通用应答别名增加独立测试。
- 完善参数示例解码、空消息报文及资源释放、元数据断言和条件字段分支测试。
- 用独立计算的固定报文验证编码和解码，修复测试暴露的相关协议字段边界问题并保留回归用例。
- 运行响应包及 JT808 模块测试、相关风格和许可证检查。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

无。本次补齐测试并检查现有协议实现，不新增规格要求，设置 `skip_specs: true`。

## Impact

主要涉及 JT808 响应消息测试及必要的消息注解修正；复用现有 JUnit 和测试基类，不引入依赖或公共 API。
