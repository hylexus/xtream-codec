# Proposal

## Why

`xtream-codec-core` 的已有测试覆盖了主要编码流程，但部分非废弃的编解码器、工具及边界分支缺少直接验证。补充行为测试，降低后续修改破坏二进制格式、缓冲区状态和异常契约的风险。

## What Changes

- 使用临时 JaCoCo 配置建立核心模块覆盖率基线，按遗漏情况选择测试目标。
- 补充非废弃代码的正常、边界和异常用例，验证输出内容及相关状态。
- 不为 `@Deprecated` 类型、方法和废弃包新增测试。
- 修复新增测试发现且用户确认一并处理的 ASCII 字符串读取类型转换异常，保留回归用例。
- 运行核心模块测试、Checkstyle 和覆盖率对比，记录结果。
- 第二轮补充 Pair/TLV 普通编解码、运行时类型、嵌套 Record 和集合测试，比较普通模式与跟踪模式的字节、结果和索引。
- 修复第二轮测试发现且用户确认一并处理的运行时嵌套编解码版本丢失问题，保留多版本回归用例。
- 第三轮补充 Map 编解码的边界、版本匹配、配置冲突及异常释放测试，以及非废弃的自定义 FieldCodec 构造选择和依赖注入测试。
- 第四轮补充 DictKey 的数值转换、字符集、精确字节和跟踪范围，以及 XtreamBitOperator 的条件重载、回调次数、可变性和位范围边界测试。
- 修复第四轮测试发现且用户确认的 GB2312 字典键返回 GbkString 类型问题，保留普通和跟踪模式的回归用例。
- 第五轮补充 Pair/TLV 扩展元数据的版本、缓存及错误配置测试，以及字段编解码器注册表的描述信息、覆盖注册和类型查找测试。
- 第六轮补充动态表达式结果的有限数值、整数和嵌套深度上限、嵌套集合快照及结果转换测试，以及动态字段定义的字符集、选项边界、派生配置和生成值冲突校验测试。
- 第七轮补充 Record 的基本类型默认值、空值策略与集合隔离，以及派生字段的版本回退、空值、只读逆变换回退和转换异常后继续解码的测试。
- 修复第七轮测试发现且用户确认的瞬态 Record 字段继续解析内部结构的问题，保留基本类型默认值和 Map 空值策略的回归用例。
- 第八轮补充 Record 派生组件无匹配版本及基本类型计算失败的边界、动态字节字段的实际值与填充和字符错误边界，以及类级与字段级属性访问策略的优先级测试。
- 修复第八轮测试发现且用户确认的 Record 派生组件无匹配版本时构造参数不足、基本类型派生值未赋值时拆箱空指针问题，保留回归用例。
- 为反射构造与字段访问测试中刻意保留的构造器、参数及字段添加成员级 Error Prone 警告抑制，验证严格编译和原有测试通过。
- 第九轮补充 EncodedLength 的容量临界值、溢出、非零写入位置与条件组合，以及公开入口 Iterable 批量编码的顺序、版本、空输入、中途失败和跟踪完整性测试。
- 修复第九轮测试发现且用户确认的 Iterable 跟踪边界问题：整批统一记录根报文、方向和失败偏移，保留回归用例。
- 第十轮补充动态编码的容器前缀容量、完整字节和固定长度边界、集合计数与条目非法输入，以及 Trace 临时缓冲区嵌套、异常恢复和 checkpoint 迁移范围测试。
- 第十一轮补充 Trace 值的标量类型保留、非废弃包装类型转换、字节无符号展示、普通对象回退与摘要长度边界，并验证 Trace 视图的实际 JSON 表示。
- 第十二轮补充调试 JSON 序列化器的数值、字符串、字节与容器输出，以及类扫描的注解模式、过滤、去重和包范围测试。
- 第十三轮补充非废弃包装类型的二进制写入、转换、空值及修改后的状态和公开编解码入口测试，以及七种长度字段的数值边界、跟踪范围和截断输入测试。
- 修复第十三轮测试发现且用户确认的 UTF8 包装类型注册错误，将 INSTANCE_STRING_UTF_8 的类型及初始化对象更正为 StringWrapperUtf8FieldCodec，保留默认注册器及普通／跟踪解码的回归用例。
- 第十四轮补充动态字段 options 的嵌套快照、只读性、标量保真与非法对象拒绝，以及表达式定义的来源互斥、参数数量、引擎绑定、集合隔离和树深度／节点数边界测试。
- 第十五轮补充瞬态字段注解代理的属性、相等性、哈希及集合使用约定，以及 XtreamMethodParameter 的缓存键区分、索引边界、泛型位置和组合注解读取测试。
- 修复第十五轮测试发现且用户确认的瞬态注解代理属性不一致及数组哈希问题：内部统一使用生效的 TRANSIENT 策略，version 数组按内容计算哈希，保留与真实注解及哈希集合对照的回归用例。
- 第十六轮通过 DataFields 的公开 JSON／对象和单字段／列表入口，补充类型别名、嵌套结构、名称及扩展属性、配置和精确编码字节的转换测试，以及非法类型、JSON、字典配置和键值的异常测试。
- 修复第十六轮测试发现且用户确认的字典 JSON 解析丢失名称和扩展属性、缺失 value 报空指针及非对象 value 被静默转为空字典的问题；仅调整 DictJsonDeserializer，保留合法空对象并增加回归测试。
- 第十七轮补充 Record 编码顺序与构造参数映射、静态常量、集合元素默认值和嵌套 POJO 长度回填的回归测试，并修复本次检查已复现的四处问题；补充实体元数据缓存、动态扩展异常与精确整数转换边界测试。
- 第十八轮补充嵌套 Record 长度隔离、集合迭代上限与长度组合、BeanUtils 缓存过滤器隔离及 POJO 实例连续解码测试；修复已复现的 Record 长度隔离和内省缓存问题，保留最大迭代次数及条件跳过字段的现有语义。

## Capabilities

### New Capabilities

无。

### Modified Capabilities

无。本次仅补充已有行为的测试，设置 `skip_specs: true`，不修改产品行为规范。

## Impact

变更涉及 `xtream-codec-core/src/test`、`XtreamByteReader.readString` 的一行修复、`RuntimeTypeFieldCodec` 的四处版本参数传递、`DataField.DictKey.deserialize` 的 GB2312 返回类型修复、`SimpleBeanMetadataRegistry` 的瞬态字段及 Record 组件占位分支、`EntityDecoder` 的 Record 基本类型派生值兜底、`EntityEncoder` 的 Iterable 跟踪边界、`DataWrapperFieldCodes` 的 UTF8 单例类型及初始化修复、`XtreamFieldUtils` 的瞬态注解代理属性及数组哈希修复、`DictJsonDeserializer` 的元数据保留及值结构校验和本变更记录，不新增正式构建依赖，不调整文档引用示例。

第十七轮还涉及 `BeanMetadata` 的 Record 构造参数顺序映射、`BeanUtils` 的 Record 组件扫描，以及 `NestedBeanPropertyMetadata` 的 Record 解码和编码长度委托；不修改废弃实现。

第十八轮还涉及 `DelegateBeanMetadataFieldCodec` 的有界切片及跟踪坐标，以及 `BeanUtils` 的缓存键与禁用缓存处理；不新增公开配置。

第十九轮补充继承和重载 setter 选择、派生位段的有符号整数反向合成，以及动态浮点特殊值和失败状态测试；修复 `BeanUtils` 选择不兼容 setter 和 `DynamicWriteExecution` 未还原补码符号的问题，不涉及废弃代码。

第二十轮补充派生位段范围与小端跨字节限制、嵌套回填值向表达式及 Tracker 传递，以及版本过滤后的集合元素和分支边界测试；仅修复 `DynamicCompiler` 中范围加法的整数溢出，不修改废弃代码。

第二十一轮补充 ByteBufContainer 工厂的缓冲区身份、释放及非零读取起点测试，并修复重复分配及数值视图忽略 readerIndex 的问题；补充动态编解码在直接、复合、切片与只读缓冲区上的行为，以及 bits 和 countOf 非法输入的失败状态测试，不修改废弃代码。

第二十二轮补充动态运行时位长度、容器消费不足和错误填充报文的测试，验证实体元数据描述及 JSON 输出，并覆盖表达式引擎编译失败的路径、偏移和原始原因；仅针对非废弃入口。

第二十三轮补充动态长度回填的容量及完整字节边界、TLV 头部在输出上限和父容器边界处写入失败，以及 POJO 多构造器选择、注解继承映射和缺少公开构造器的测试；保留原有行为，不涉及废弃代码。

第二十四轮补充 array／TLV／map／pair 按项计数前缀的 0、255、256 容量边界，以及反射、MethodHandle、Lambda 属性访问中 getter、普通及链式 setter 抛异常时的原始原因、输入输出状态和跟踪诊断测试；仅针对非废弃入口。

第二十五轮补充 EncodedLength 与派生、瞬态字段共存及被跳过字段作为范围边界的测试，以及 ISO-2022-JP 字符串在 flush 阶段扩容、恰好容纳和超限的测试；仅新增非废弃行为测试及验证记录。

第二十六轮补充实体长度及迭代次数表达式返回 null、抛异常时的真实解码状态，以及调试服务在输入／输出资源上限为零、刚好足够和超限时的响应测试；仅增加非废弃入口的测试和验证记录。

第二十七轮补充实体 Map 在写键、长度及复制值时输出容量不足的测试，以及动态定长字节字段的值偏短且未声明填充规则的测试；验证部分输出、临时资源释放、跟踪诊断和后续调用恢复，仅针对非废弃入口。

第二十七轮测试复现非零报文起点下临时 Value 跟踪范围被压缩、迁移位置额外包含报文起点的问题；用户确认一并修复 CodecTraceRecorder 的临时缓冲区坐标隔离与迁移计算，保留失败证据和回归测试。

第二十八轮补充实体 condition 表达式返回 null、抛异常及后续恢复的测试，以及实体前置长度占位和内容编码时输出容量不足的测试；核对普通／跟踪模式的部分进度、对象状态和诊断，仅新增非废弃行为测试及验证记录。

第二十九轮补充动态结构的编译深度上限、非整数引用及非法 countOf 目标测试，对照 Java／JSON 入口和合法定义；补充动态条件的严格比较等值边界、位掩码不成立和相邻数组项隔离测试，核对普通／跟踪编解码的字节、结果和范围，仅针对非废弃入口。

第三十轮补充 computedLengthOf 非法区间的 Java／JSON 编译校验及合法往返对照、字节字段长度前缀在父容器和全局输出边界不足时的提前拒绝，以及必需扩展字段缺失或显式 null 时的调用隔离与恢复测试；仅增加非废弃行为测试和验证记录。

第三十一轮补充单值 Pair／TLV 的实体编码、空值、跟踪与 TLV 临时缓冲区释放测试，公共 Key／ValueLength 元数据的版本冲突与数组顺序测试，以及动态扩展非法标识和配置异常的 Java／JSON 编译校验；仅针对非废弃入口。

第三十一轮测试复现 HasVersions 使用二分查找检查未排序版本数组，导致 ALL_VERSION 放在末尾时混用配置未被拒绝；用户确认一并修复为不依赖顺序的成员检查，不修改调用方数组，保留 Key／ValueLength 的失败回归。

第三十二轮补充自定义 Map 编解码器按实体类／自定义 Codec 类注册、版本传递、有界／无界解码及非法注册和未知键测试，动态条件／长度定义的 Java／JSON 校验和合法往返测试，以及 OR 右操作数成功求值和 NOT(false) 对条件字段及跟踪范围的影响；仅针对非废弃入口。

第三十二轮测试复现无界 Map 跟踪解码将前置字节包含进 Map 节点 HEX，用户确认一并修复。仅记录并使用 AbstractMapFieldCodec.deserializeWithTracker 开始读取 Map 时的实际索引，不改变解码结果、输入消费和节点范围，保留非零报文起点及两个版本的回归。
