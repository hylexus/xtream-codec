文档字体来源与分发说明
Documentation font source and distribution notes

本目录的三个 WOFF2 字体直接提取自官方 npm 包 @fortawesome/fontawesome-free 6.7.1。
The three WOFF2 fonts in this directory are extracted directly from the official npm package @fortawesome/fontawesome-free 6.7.1.

字体内容保持上游原始字节，未进行子集化、格式转换或内部名称修改；仅沿用项目已有的本地文件名。
The font contents retain the original upstream bytes without subsetting, format conversion or changes to internal names; only the project's existing local filenames are used.

本地文件与官方归档成员的对应关系如下。
The local files map to the following members of the official archive.

free-fa-brands-400.woff2  <- package/webfonts/fa-brands-400.woff2
free-fa-regular-400.woff2 <- package/webfonts/fa-regular-400.woff2
free-fa-solid-900.woff2   <- package/webfonts/fa-solid-900.woff2

Official fixed-version source:

这三个字体适用 SIL Open Font License 1.1（OFL-1.1），完整条款见同目录 LICENSE.txt 的 Fonts 部分。
These three fonts are licensed under the SIL Open Font License 1.1 (OFL-1.1); see the Fonts section of LICENSE.txt in this directory for the complete terms.

LICENSE.txt 保留 Font Awesome Free 的原始完整复合许可，其中 SVG/JS 图标和配套代码的许可分别说明；字体适用其中的 OFL 条款。
LICENSE.txt retains the original complete composite license for Font Awesome Free, which separately describes the licenses for SVG/JS icons and accompanying code; the fonts use its OFL terms.

项目 Apache-2.0 许可不替代字体的 OFL-1.1 许可。
The project's Apache-2.0 license does not replace the fonts' OFL-1.1 license.

OFL 允许将字体放入仓库、嵌入网站，并随软件进行开源或商业分发；每份分发须保留字体版权和完整许可，字体本身继续按 OFL 提供。
The OFL permits including the fonts in a repository, embedding them in a website, and distributing them with open-source or commercial software; each distribution must retain the font copyright and complete license, and the fonts themselves remain under the OFL.

不得单独出售字体。修改版若将保留字体名“Font Awesome”用作向用户显示的主字体名，须取得著作权人的明确书面许可。
The fonts must not be sold by themselves. Using the Reserved Font Name "Font Awesome" as the primary font name shown to users of a modified version requires explicit written permission from the copyright holder.

除注明贡献或取得明确书面许可外，不得使用上游著作权人或作者的姓名为修改版宣传、背书或做广告。
The upstream copyright holder's or authors' names must not be used to promote, endorse or advertise a modified version, except to acknowledge their contributions or with explicit written permission.

本项目的文档构建随字体复制本说明和 LICENSE.txt，并将两者全文纳入站点生成的 THIRD-PARTY-FRONTEND-NOTICES.txt；分发文档站时一并保留这些材料。
The project's documentation build copies these notes and LICENSE.txt alongside the fonts and includes both texts in the site's generated THIRD-PARTY-FRONTEND-NOTICES.txt; retain these materials when distributing the documentation site.

这是本项目的材料组织方式；OFL 对版权和许可保留的要求见上文及 LICENSE.txt。
This is the project's arrangement for distribution materials; see above and LICENSE.txt for the OFL requirements to retain copyright and license notices.

本说明由项目编写，用于解释来源和分发方式，不修改上游许可条款。版本、归档成员及来源见上文；升级时同步更新本说明和原始许可，构建检查字体及材料是否完整复制，不维护额外审查哈希。
These project-authored notes explain the source and distribution arrangements without modifying upstream license terms. See above for the version, archive members and source. On upgrades, update these notes and the original license; build checks verify complete copying of the fonts and materials without maintaining additional review hashes.
