前端补充许可与归属
Supplemental frontend licenses and attributions

本文件集中保存少量 npm 包未随包附带的许可原文，由各前端共用；不是全部依赖清单，各节仅适用于实际包含的相应组件。
This file collects original license texts omitted from a small number of npm packages and is shared by the frontends. It is not a complete dependency inventory; each section applies only where the corresponding component is included.

构建优先收集安装包自带的完整许可与声明。缺少许可正文时，仅对下列按包名列明且元数据声明 MIT 的包采用本补充；不绑定具体版本，也不以许可短名生成替代正文。
Builds collect complete licenses and notices supplied by installed packages. When license text is missing, this supplement covers only the named packages below that declare MIT in their metadata. It is not tied to exact versions and does not generate replacement text from a license identifier.

比较版本和固定来源用于说明原文依据；依赖升级时按上游许可与发行材料更新适用段落，无需维护逐版本放行表或额外审查哈希。
Comparison releases and fixed sources identify the basis for the texts. Update applicable sections using upstream licenses and release materials on upgrades, without maintaining per-version approval tables or additional review hashes.

版权、许可和免责原文保持完整。以下作者和权利人属于上游归属，不表示参与或背书本项目；项目 Apache-2.0 不替代第三方许可。
Original copyrights, licenses and disclaimers are retained. Authors and rights holders below identify upstream attribution, without implying participation in or endorsement of this project; the project's Apache-2.0 license does not replace third-party licenses.
