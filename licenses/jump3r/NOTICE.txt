重建和替换
Rebuilding and replacement

仓库中的工具位于 build-script/license/jump3r.py；分发归档中，工具与匹配源码同目录。解压该目录后，使用 Python 3.9+ 与 JDK 11+ 执行。以下以 1.0.5 为例，其他版本使用实际分发的源码文件名：
The tool is maintained in build-script/license/jump3r.py and distributed beside the matching sources. After extracting that directory, run with Python 3.9+ and JDK 11+. The example uses 1.0.5; for other versions, use the actual distributed source filename:

python3 jump3r.py rebuild jump3r-1.0.5-sources.jar --output jump3r-rebuilt.jar

工具编译为 Java 8 字节码。重新编译的 JAR 可能与上游二进制存在字节差异，可供需要替换依赖的应用重新构建。对于未签名、无前置启动脚本且包含唯一 BOOT-INF/lib/jump3r-*.jar 的 Spring Boot JAR，可执行以下命令直接替换嵌套库。
The tool compiles to Java 8 bytecode. The rebuilt JAR may differ in bytes from the upstream binary and can be used when rebuilding an application with the replacement dependency. The following commands replace the nested library in an unsigned Spring Boot JAR with no prepended launch script and exactly one BOOT-INF/lib/jump3r-*.jar entry.

python3 jump3r.py replace application.jar jump3r-rebuilt.jar --output application-relinked.jar
java -jar application-relinked.jar

替换工具保留原应用，输出必须是新文件；仅替换唯一的 BOOT-INF/lib/jump3r-*.jar，保留其他条目及索引，嵌套库不压缩。带签名或前置 shell 脚本的发行物需另行提供重建/签名方法。
The replacement tool preserves the original application and requires a new output file. It replaces only the unique BOOT-INF/lib/jump3r-*.jar, preserving other entries and indexes and storing the nested library without compression. Signed distributions or those with prepended shell scripts require separate rebuilding/signing methods.

选择与应用接口兼容的修改版并验证实际编码功能。再分发时，按适用许可提供与实际分发库相对应的源码、构建材料和修改声明。使用本项目的归档校验时，还应更新 ARTIFACTS.txt 中的校验值，使其与实际分发的源码和二进制一致。
Choose an interface-compatible modified version and verify that encoding works. When redistributing, provide the corresponding sources, build materials, and modification notices as required by the applicable license. When using this project's archive checks, update the checksums in ARTIFACTS.txt to match the distributed sources and binary.

使用者可修改和替换该库；应用条款不得禁止 LGPL 为调试修改库所允许的逆向工程。打包形式不代替 LGPL 的其他要求，发布 ZIP、镜像等时须保留这些材料。

===== BEGIN lame-3.98.4/mpglib/README =====
hip - Hip Isn't a Player
A LGPLed mpeg audio decoding library.

Based off of Michael Hipp's mpglib 0.2a <http://www.mpg123.de/>, with many
improvements by the lame development team (see AUTHORS).

The interface to the library is based off of vorbisfile.  If you add mp3
support to your app using this library it should be a snap to add Ogg Vorbis
support as well.

This isn't as fast as mpg123 will be for decoding as none of it is in
assmbler.  

Seeking currently isn't implemented.
